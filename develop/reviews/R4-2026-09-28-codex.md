
clone 검산은 최종 smoke test 로 충분하다. 하지만 매번 수동 clone 에 의존하지 말고 위 검사를

`models`, `rules`, `src` 만 보고 `develop/sync_results_branch.py` 는 보지 않는다. 이번
MANIFEST 생성 시각도 exporter 커밋보다 앞이므로, 수정된 exporter 가 커밋되기 전에 실행된
것으로 보인다. **최종본은 exporter 수정과 MANIFEST 부분갱신 수정을 커밋한 뒤 clean `HEAD`
