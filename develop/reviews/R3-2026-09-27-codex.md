## publish 차단 사항 (원문 요지)

1. **expected footprint 가 독립 승인 입력이 아니다.** 적용기가 실행할 때 refmatch 로
   expected 를 다시 만들고 actual 과 함께 출력한다. 문서의 `--expected` 인자도 parser 에
   없다. 따라서 digest 일치는 "두 구현이 일치했다" 는 증거이지 "사전에 승인된 변경 허용
   목록을 지켰다" 는 증거가 아니다.
   (PLAN:145 / plus_at_apply.py:456 / plus_at_apply.py:437)

2. **"V9 12 종 재실행 통과" 주장이 코드와 맞지 않는다.** 실제로는 metadata 보존,
   dependency, layers/repeat 정도다. 다음은 이름만 있고 실질 검사가 없거나 불완전:
   `expression_no_cycle`(명시값을 먼저 환경에 넣으므로 순환 expr 도 통과),
   `zero_axis_only_initial_residual`(위치 미검증, 개수만 보고),
   `batch_seq_head_axis_consistency`, `head_scope_exclusive`,
   `moe_quotient_remainder_consistency`, `prefill_decode_structure`,
   `op_id_dag`(dict 변환 때문에 중복 op_id 검출 불가).
   "검증 V1~V9 통과" 는 실제보다 강한 표현이다.
   (plus_at_apply.py:277 / :382)

3. **release gate 가 검토 상태를 강제하지 않는다.** substitution 네 개의 `status` 만 본다.
   V9 `review_status` 는 매번 무조건 `proposed` 로 기록되며 `semantic_evidence_verified:
   false` / `point_verified: null` 이어도 release 가 가능하다.
   (plus_at_apply.py:501 / :566 / overlay:108)

4. **R1/R2 완료 기록이 없다.** `develop/reviews/` 디렉터리와 기록이 없고 overlay 는 의미
   검증을 전부 false 로 표시한다. 원문·prompt/source hash·판정 반영 내역이 먼저 들어와야
   한다. 이 세션은 제안식까지 이미 봤으므로 blind R1 을 대신할 수 없다.

5. **`not_applicable` 3 종을 현재 사유로 승인할 수 없다.** "발행본만으로 재구성할 수 없다"
   는 `not_applicable` 이 아니라 `not_evaluated` 에 가깝다.
   - `axis_class_consistency`: 이번 작업이 축 의미를 바꾸므로 직접 관련. sidecar/crosswalk
     로 실행하거나 미검증으로 남길 것
   - `reshape_derivation`: 구조는 그대로지만 symbolic label 이 바뀌므로 재검사하거나
     불변 승계의 구체적 증명을 기록할 것
   - `port_coverage`: 포트 구조 불변을 base sidecar hash + cell-key 불변으로 증명하면
     `inherited_unchanged` 가 더 정확
   저장소에 실제 sidecar 가 있으므로 "없다" 는 설명도 정확하지 않다.

6. **재현성 메타데이터가 잘못됐다.** MANIFEST 의 `tool.git_commit` 이 `86353fd1…` 인데 그
   커밋에는 `develop/plus_at_apply.py` 가 없다(`03ac71ae…` 에서 추가됨).
   `base_results_commit` 과 `tool_source_commit` 을 분리할 것. 파일별 SHA-256 은 정확하다.

7. **부수적 문서 불일치.** R3 문서는 fixture 16 개라고 하지만 실제로는 일반 14 + 산술 4.
   계획의 `DIFF.md` 가 없다. `symbols.yaml` 의 kind 구분이 CSV/JSONL 단독 배포에서는
   전달되지 않으므로 "표와 symbols.yaml 은 분리 불가이며 미등록 심볼은 거부한다" 는
   소비자 계약이 MANIFEST 나 README 에 필요하다.
